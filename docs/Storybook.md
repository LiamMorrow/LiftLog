# Storybook

On-device Storybook (`@storybook/react-native`) for the foundation components. Stories render inside
the real app, so they pick up the live theme, native expo-ui controls and every provider.

## Running it

- `npm run storybook` (from `app/`) starts the dev client with `EXPO_PUBLIC_STORYBOOK_ENABLED=true`.
- The app pushes the `/storybook` route on launch while that variable is set.
- With the variable unset, Metro stubs Storybook out of the bundle, so release builds do not include it.

## Writing stories

- Colocate `*.stories.tsx` next to the component in `components/presentation/foundation/`.
- Only that folder is scanned; widen `stories` in `app/.rnstorybook/main.ts` to cover more.
- Use `fn()` from `storybook/test` for callback args so they show in the Actions tab.
- `.rnstorybook/storybook.requires.ts` is generated by Metro on start, or by `npm run storybook:generate`.
  Commit it when stories are added or removed.
- Light/dark follows the app's theme setting
