# Storybook

On-device Storybook (`@storybook/react-native`) for the foundation components. Stories render inside
the real app, so they pick up the live theme, native expo-ui controls and every provider.

## Running it

- `npm run storybook:start` (from `app/`) starts the dev client with `EXPO_PUBLIC_STORYBOOK_ENABLED=true`.
- The app pushes the `/storybook` route on launch while `EXPO_PUBLIC_STORYBOOK_ENABLED` is set.
- With `EXPO_PUBLIC_STORYBOOK_ENABLED` unset, Metro stubs Storybook out of the bundle, so release builds do
  not include Storybook.

## Writing stories

- Colocate `*.stories.tsx` next to the component in `components/presentation/foundation/`.
- Only `foundation/` is scanned; widen `stories` in `app/.rnstorybook/main.ts` to cover more folders.
- In order to show callback args in the Actions tab, use `fn()` from `storybook/test` for them.
- `.rnstorybook/storybook.requires.ts` is generated by Metro on start, or by `npm run storybook:generate`.
  Commit `storybook.requires.ts` when stories are added or removed.
- Light/dark follows the app's theme setting.
